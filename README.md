# MLFileManager

Gestore di file per Android delle **MLapps**, ispirato a File Manager+, in stile Material You con il tema condiviso [MLTheme](https://github.com/marco90-cyber/MLTheme).

## Cosa fa

- **Home** con lo spazio usato e le categorie: Download, Immagini, Audio, Video, Documenti, Applicazioni, Nuovi file, Sistema, Cestino
- **Cartelle**: percorso in alto, ordinamento, ricerca nelle sottocartelle, nuova cartella / nuovo file
- **Selezione multipla**: copia, taglia e incolla, condividi, comprimi in ZIP, elimina, rinomina, proprietà (con MD5 / SHA-256)
- **Archivi ZIP**: estrai qui o in una nuova cartella
- **Cestino** (si può disattivare)
- **Analisi archiviazione**: categorie, app più pesanti, file grandi, cache, download duplicati
- **Applicazioni**: app installate e file APK, con apri, info, salva APK, condividi, disinstalla
- **Accesso da rete**: server **FTP** e accesso dal **browser** (porta + 1), con password, password casuale, file nascosti e sola lettura
- **Visualizzatori integrati**: foto (zoom, sfondo), video, musica, editor di testo
- Aggiornamenti dall'app tramite le Release di GitHub

## Requisiti

Android 12 o successivo. L'app chiede il permesso **Accesso a tutti i file**; per lo spazio reale delle app e la cache serve anche **Accesso ai dati di utilizzo**.

## APK

Ogni modifica su `main` viene compilata da GitHub Actions: l'APK si trova nella sezione **Releases**.
